Exported API, one line per type/function group:
- Launch: trusted harness/profile, paths, launch/member/session identity, Resume,
  ExtraEnv, and optional Model selector. Validate rejects unsafe ids, nonabsolute
  paths, NUL/newline paths, invalid sessions, and identity/config env overrides.
- Launch.TokenPath: caller-owned token path, referenced without writing a token.
- Launch.OwnedPaths(home): token, delivery directory, generated configs, and Claude
  pointer, for caller cleanup; only the delivery directory needs recursive removal.
- WriteFiles: private per-launch Claude MCP/settings and OpenCode MCP/permission
  files using statedir; Codex and pi require no generated configuration files.
- ClaudeHookSettings: silent POSIX sh / Windows PowerShell SessionStart hook with
  no pruning. ReadPointer: last complete valid non-subagent session, or empty.
- Args / Environment: pure argv and environment builders for first/resumed turns
  and panes, every harness/profile combination; pi headless returns the shared
  harness_unavailable error. Codex/OpenCode panes require a reported session first.
- Event / Parser / NewParser / Parser.Line / Parser.Finish: single acknowledgement,
  session changes, last assistant text, nullable model.Usage, and failure evidence.
- Outcome / Status: process result and pure succeeded/failed/cancelled/timed_out
  mapping using model enums; explicit provider errors count even with exit zero.
- Resolver / Driver / Driver.Start: injectable executable discovery for tests;
  default hostprobe Binary plus version/support checks, native .exe only on Windows.
- Start / Handle: prompt on stdin then EOF, immutable PID and buffered Events;
  concurrent/repeatable Wait and Cancel, context cancellation/deadlines, bounded
  stream draining, POSIX groups plus detached-descendant cleanup, Windows jobs.

Choices where the spec is silent:
- Optional trusted Model allows cheap test/caller model choices. No free-form argv
  extension exists. Claude/Codex use lowercase UUID syntax; OpenCode sessions use
  ses_ plus 1-128 ASCII alphanumerics. ExtraEnv keys use portable identifier syntax.
- Environment returns overrides; Driver merges with inherited env case-insensitively
  on Windows. Inherited OPENCODE_CONFIG_CONTENT is removed so it cannot shadow the
  launch config. Identity and OPENCODE_CONFIG overrides are reserved. C2d must apply
  the equivalent removal/overrides when it launches panes.
- Events deliberately contains only one buffered acknowledgement and closes after
  completion; it cannot stall Wait if the runner is not consuming progress events.
- Explicit provider/result errors override exit zero. Absent completion/final text
  is failure even after acknowledgement. Unknown event types are ignored; malformed
  JSON is mentioned only on otherwise failed turns. Stderr is bounded to 16KB,
  event lines to 4MiB, total event output to 64MiB, and pipe draining to one second.
- OpenCode text blocks are combined within a message and reset at a new messageID,
  so only the last assistant message is returned. Its v2 stream often omits
  step_finish/usage; final text plus clean exit/ack is completion evidence here.
  Unlike the reference worker's v2 transcript-export check, this driver does not
  spawn an auxiliary export command. Fields absent from the stream remain nil.
- Cancellation uses immediate SIGKILL / job termination for predictable teardown,
  supplemented on Linux/macOS by an ancestry snapshot for detached descendants.
  An already orphaned/reparented descendant cannot be rediscovered by ancestry;
  this is process control, not isolation from a hostile process trying to escape.
- Pointer parsing ignores malformed records, invalid UUIDs and partial final lines;
  agent_id present even as null marks a subagent record. A missing file means none.
- Own paths include the optional delivery directory although this package creates
  no pane delivery files. The caller owns cleanup, token writes and pointer deletion.
